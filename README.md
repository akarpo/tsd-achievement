# G3-G7 Achievement Across 8 Districts · 2019-2025

Multi-state grade-level achievement comparison for eight high-performing suburban districts in five states, with full demographic disaggregation (race, special education, English learner, economic disadvantage, gender) for Math and ELA.

**Live dashboard:** https://akarpo.github.io/Achievement/

## What's here

- **`index.html`** — standalone interactive dashboard (Chart.js, no build step). Slicers for subject, grade band (G3-G5 / G6-G7 / G3-G7), districts, and subgroups. Each line on the chart is one (district × subgroup) trend.
- **`G3-G7_Achievement_Data.xlsx`** — the underlying tidy data, downloadable from the dashboard header.
- **`Working Folder/`** — extractors, rebuild tooling, source CSVs, and a per-session change log. Not needed to view the dashboard; only relevant if you want to refresh or rebuild the data.

## Districts

Bellevue SD (WA) · Coppell ISD (TX) · Dublin USD (CA) · Milpitas USD (CA) · Palo Alto USD (CA) · Troy SD (MI) · Walnut Valley USD (CA) · West Windsor-Plainsboro RSD (NJ)

## Data sources

State assessments, pulled directly from each state's reporting system:

| State | Assessment | Source |
|-------|-----------|--------|
| Michigan | M-STEP | MI School Data |
| California | CAASPP | CDE Smarter Balanced |
| Texas | STAAR / TAPR | TEA |
| New Jersey | NJSLA | NJ DOE |
| Washington | SBA (Smarter Balanced) | OSPI Socrata API |

> ⚠️ **Cross-state caveat.** Each state sets its own proficiency cut score, so absolute % proficient is **not** comparable across states. Within-district trends over time **are** comparable.

## Rebuilding the data

If you want to refresh from source:

```bash
cd "Working Folder/Cache and Tools"
chmod +x rebuild.command   # one-time
./rebuild.command
```

This regenerates `G3-G7_Achievement_Data.xlsx` at the repo root. `index.html` is hand-edited and not regenerated by the build.

See [`Working Folder/README.md`](Working%20Folder/README.md) for the full tooling inventory and [`Working Folder/CHANGELOG.md`](Working%20Folder/CHANGELOG.md) for the per-cell audit trail of corrections.
